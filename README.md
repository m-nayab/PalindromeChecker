Palindrome Checker

This project checks if a given word or phrase is a palindrome. A palindrome reads the same backward as forward, ignoring spaces, punctuation, and capitalization.

Technologies Used:

HTML: For structuring the user interface (input field, button, and display area).
CSS: For styling the appearance of the webpage (colors, fonts, layout).
JavaScript: For implementing the palindrome checking logic and updating the user interface.
Installation:

Clone the repository:
Bash

git clone https://github.com/m-nayab/PalindromeChecker.git
Open the project in a code editor:

Open the cloned project folder in your preferred code editor (e.g., Visual Studio Code, Sublime Text).

Usage:

Open the index.html file in a web browser.
Enter a word or phrase in the input field.
Click the "Check" button.
The result will be displayed1 below, indicating whether the input is a palindrome or not.

Project Structure:

index.html: The main HTML file for the webpage.
style.css: The CSS file for styling the webpage.
script.js: The JavaScript file containing the palindrome checking logic.
